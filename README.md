## 从香港到大陆，路其实就那么几条

中国大陆用户访问香港服务器，回程无非走这几条：

- **163 骨干网（AS4134）**：最便宜、最挤。白天能用，晚高峰全国流量一起压上来，延迟翻倍、丢包上两位数很常见。
- **CN2 GT**：去程走 CN2，回程可能掉回 163，属于“半程高速”，卖家常把它简写成“CN2”卖给你。
- **CN2 GIA（AS4809）**：全程走 59.43 开头的专属节点，不经过 163 拥堵段。这是电信体系里等级最高的线路，也是香港低延迟方案里最贵的那一档。
- **CMI（AS58453）**：中国移动国际自建线路，移动用户走这条回国延迟最低，对电信、联通用户加速效果一般。
- **联通 9929 / 4837**：9929 是联通精品网，4837 是普通国际出口，两者体验差得不小。
- **国际线路（NTT、RETN、GSL 等）**：面向全球互联优化，对香港到欧洲、东南亚的延迟很友好，但对中国大陆基本没有专项优化。

判断“低延迟”真假，最直接的办法是自己跑一遍路由。Windows 下 `tracert`、Linux 下 `mtr` 你的服务器 IP，如果节点里成片出现 `59.43.*.*`，基本可以确认是 CN2 GIA；如果一路全是 `202.97.*.*`，那就是普通 163 线路，销售页写什么都没用。

## 延迟数字该怎么读

不同来源的实测数据会有出入，但大致区间是稳定的：

| 线路类型 | 华南地区延迟 | 华东地区延迟 | 晚高峰表现 |
| --- | --- | --- | --- |
| CN2 GIA（双向） | 15–30ms | 35–55ms | 波动小，接近 0 丢包 |
| CMI | 20–45ms | 35–60ms | 移动用户稳定 |
| 普通 163 | 30–50ms | 40–80ms | 高峰期丢包明显 |
| 纯国际线路 | 视运营商而定，可能高于美西 | 同左 | 不保证 |

两点需要提醒。第一，华南和华东的差距主要来自物理距离（香港到广州约 120 公里，到上海约 1200 公里），这部分靠线路优化补不回来。第二，白天测出来的延迟没什么参考价值，晚上九点到十一点的数字才决定你的实际体验。

## 下单前值得知道的几件事

**EB 是 Beta。** 这一点最容易被忽略。官方页面明确标注了 Eyeball 网络仍在优化中，去程回程路由都可能变。今天测出来移动走 CMI 很好，不代表三个月后还是这样。

**T1 不要给国内用户用。** 这不是“差一点”，而是“方向错了”。T1 的设计目标是国际互联，中国大陆没有专项优化，电信和联通用户的实际体验可能还不如美西机房。如果你的客户在国内，这条线路选错了，钱和体验一起损失。

**超流量的处理方式不一样。** T1 和 Pro 的流量跑完后是降速继续用，不会直接停机断网；这一点对流量波动大的项目比较友好。但不同档位的降速值不同，WEE 只有 50Mbps，高配档能到几百 Mbps，选的时候留心。

**退款和换 IP。** 按目前公开的条款，购买后 3 天内、流量使用不超过 30GB 可以申请全额退款（扣除支付网关手续费），30 天内可以按剩余时长申请部分退款；续费订单、余额支付、同一系列已退款超过 3 次的情况不在退款范围内。IP 被墙可以申请更换，一般每 15 天可免费换一次，其他情况换 IP 收费。这些条款以官网当时公布的内容为准，下单前建议自己再确认一遍。

**支付方式。** 支付宝、微信、PayPal、信用卡都支持，对国内用户没有门槛。注册时注意关闭代理工具，用真实信息填写——风控系统对异常 IP 和伪造信息是会直接触发自动退款的。

## 常见问题

**香港和日本、新加坡比，延迟优势明显吗？**
对华南用户来说优势明显，香港优质线路可以压到 20ms 上下，日本通常在 50–70ms，新加坡 60–80ms，美西走 CN2 GIA 也要 150ms 左右。但这是华南的情况，华北用户走哪都是 40ms 起步，差距会缩小。

**CN2 GIA 和 CMI 到底选哪个？**
看你的用户用什么网。电信用户多选 CN2 GIA，移动用户多选 CMI。如果你的用户三类运营商都有，那 Premium 这种三网都做优化的方案更省心，代价是价格高一档。

**为什么同样标“CN2”，价格能差好几倍？**
因为 CN2 里还有 GT 和 GIA 的区别。GT 只在部分路径走 CN2 节点，GIA 才是全程独立通道。带宽成本差着数倍，售价自然差数倍。买之前用 traceroute 看 59.43 节点的覆盖比例，比看销售页上的“CN2”两个字靠谱。

**流量超了会怎样？**
DMIT 香港的 T1 和 Pro 系列都是降速不限量，不会直接断服。T1 的 WEE 超量后限速到 50Mbps，高配档能到 1Gbps。如果你的业务有明显的流量峰值，这个设计比“超了就停机”友好得多。

**可以先买一个月试吗？**
可以，而且建议这么做。月付能跑通线路验证，年付再用优惠码锁折扣，这个顺序比反过来安全。
